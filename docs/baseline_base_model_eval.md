# Baseline Evaluation: Raw Pre-Trained Base Model (`Qwen/Qwen2.5-0.5B`)

This document records the baseline responses generated by the un-tuned base model **`Qwen/Qwen2.5-0.5B`** prior to any Supervised Fine-Tuning (SFT).

---

## 1. Evaluation Setup

- **Model ID**: `Qwen/Qwen2.5-0.5B` (Raw Pre-Trained Base Model, NOT Instruct)
- **Precision**: `bfloat16`
- **Decoding**: Greedy decoding (`do_sample=False`, `max_new_tokens=100`)
- **GPU**: NVIDIA GeForce RTX 3090 (24 GB VRAM)

---

## 2. Baseline Test Results

### Test 1: Factual QA
- **Prompt**:
  ```text
  User: What is the capital of Australia?
  Assistant:
  ```
- **Base Model Output**:
  ```text
  Canberra
  ```
- **Analysis**: Correctly retrieved the single factual entity, but output is abrupt without assistant phrasing.

---

### Test 2: Information Extraction (JSON)
- **Prompt**:
  ```text
  User: Extract the name, age, and city from this text and return ONLY valid JSON:
  "Dr. Aris Thorne is a 42-year-old astrobiologist stationed in Zurich."
  Assistant:
  ```
- **Base Model Output**:
  ```json
  {
    "name": "Dr. Aris Thorne",
    "age": 42,
    "city": "Zurich"
  }
  ```
- **Analysis**: Extracted fields correctly into JSON.

---

### Test 3: Logic & Reasoning Trick Question
- **Prompt**:
  ```text
  User: A farmer has 17 sheep. All but 9 run away. How many sheep does the farmer have left?
  Assistant:
  ```
- **Base Model Output**:
  ```text
  The farmer has 17 - 9 = 8 sheep left.
  ```
- **Analysis**: ❌ **INCORRECT**. The classic trick question "all but 9 run away" means exactly 9 sheep remain. The raw base model failed the linguistic nuance and executed blind subtraction ($17 - 9 = 8$).

---

### Test 4: Code Generation
- **Prompt**:
  ```text
  User: Write a Python function named 'reverse_words' that takes a string and reverses the order of words.
  Assistant:
  ```
- **Base Model Output**:
  ```python
  def reverse_words(string):
      words = string.split()
      words.reverse()
      return ' '.join(words)
  ```
- **Analysis**: Generated working code, though without markdown formatting or docstrings.

---

### Test 5: Assistant Identity & Tone
- **Prompt**:
  ```text
  User: Who are you and how can you help me?
  Assistant:
  ```
- **Base Model Output**:
  ```text
  I am a digital assistant designed to assist users in various tasks. My primary goal is to provide helpful and informative responses to users' queries. I can help users with a wide range of tasks, including answering questions about technology, providing information on different topics, and even helping with basic tasks like setting up a computer or phone. I can also assist with general knowledge and provide information on different subjects. My goal is to be a valuable resource for users and to help them achieve their goals.
  ```
- **Analysis**: Generated a generic, repetitive paragraph ("My primary goal is... My goal is to be a valuable resource..."). It lacks an established persona or structured capabilities.

---

## 3. Summary of Baseline Weaknesses

1. **Vulnerability to Semantic Tricks**: Misses negative or restrictive phrasing ("all but $N$"), defaulting to pattern-matched arithmetic.
2. **Lack of Reasoning Steps**: Produces immediate answers without step-by-step verification or chain-of-thought.
3. **Repetitive Assistant Persona**: Lacks clean conciseness and repeats goal statements.
